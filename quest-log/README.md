# 人生任务局 · Questlog

手机和电脑可访问的游戏式任务日志。静态前端不依赖构建工具。

## 已实现

- 主线 / 支线，任务领域、优先级、状态和难度。
- 主线拆步骤，支线关联主线；完成 / 重新开启 / 编辑 / 删除。
- DDL 精确到分钟、临期与逾期提示、截止时间轴。
- 今日聚焦最多三项。
- 经验、等级、三种成就、完成记录和自定义奖励。
- 当前浏览器持久保存，跨标签页修改冲突保护。
- JSON 导入 / 导出；ICS 日历导出，UTF-8 正确折行。
- 初次打开为明确标记的示例存档，可清空示例开启个人存档。

## 当前同步状态

`config.js` 暂未配置服务，线上当前仅使用设备本地存档，不会跨设备自动同步。不要清理浏览器数据前不做备份。

`sync.js` 已准备 Supabase 邮箱登录、注册、读取和上传的接口。配置后为手动同步，不能称作自动同步。真实服务尚未连接，因此认证、RLS 和云端并发行为尚未经过真实环境验证。

连接 Supabase 后：先在选定项目运行 `supabase.sql` 创建账号隔离的表、RLS 和原子版本检查函数；配置 Auth 的站点 URL / 邮件确认重定向。`config.js` 只允许填写项目 HTTPS URL 和 publishable / anon 公钥，绝不能填 service-role 密钥。部署修改后的 config.js。之后再验证两个账号之间的隔离及两个设备的版本冲突。用户的任务存档和登录会话不进入源码仓库。

## 本地运行

在此目录运行 `python -m http.server 4187 --bind 127.0.0.1`，打开 http://127.0.0.1:4187/。

## 验证

`node --test test-core.mjs`：DDL、XP、导入校验、父子关联、聚焦上限、ICS 和空存档。

已通过浏览器实测：新建带 DDL 和步骤的关联支线、逐步勾选、任务完成与经验、归档、刷新恢复、390×844 手机布局、存档入口。
